# Шрифты для приложения

Положите сюда файлы шрифтов:

- `Lora-Regular.ttf` —regular начертание заголовков
- `Lora-Bold.ttf` —жирное начертание заголовков
- `Manrope-Regular.ttf` —обычное начертание основного текста
- `Manrope-Bold.ttf` —жирное начертание основного текста

Шрифты можно скачать бесплатно:
- **Lora**: https://fonts.google.com/specimen/Lora
- **Manrope**: https://fonts.google.com/specimen/Manrope

После добавления файлов выполните `flutter pub get`.
