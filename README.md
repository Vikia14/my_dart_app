# My Dart App

This is a simple Dart application that serves as a starting point for Dart development.

## Project Structure

```
my-dart-app
├── bin
│   └── main.dart
├── pubspec.yaml
└── README.md
```

## Getting Started

To run this application, make sure you have Dart installed on your machine. You can download it from [dart.dev](https://dart.dev/get-dart).

### Running the Application

Navigate to the project directory and run the following command:

```
dart run bin/main.dart
```

This will execute the application and you should see "Hello, World!" printed in the console.
